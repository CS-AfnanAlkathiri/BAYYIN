# Roadmap

The following are planned extensions, not claims about the current build.

1. Expand the approved corpus through provenance-preserving ingestion and qualified scholarly review.
2. Freeze retrieval thresholds and create a genuinely independent evaluation set.
3. Evaluate a stronger multilingual embedding backend such as BGE-M3 on the expanded corpus.
4. Add and independently validate an entailment/contradiction component for claim-to-evidence relationship analysis.
5. Build a human-reviewed benchmark for grounded RAG explanations: factual support, citation faithfulness, abstention, and Arabic/English quality.
6. Measure end-user outcomes such as verification time, task completion, clarity, and calibration of trust.
